# 게임잡 실제 공고 적용 테스트

확인일: **2026-11-03** · 수정 전 기준 커밋: `c4d4292`

게임잡에 게시된 실제 공고 7건에 스킬을 적용하고, 생성한 분석을 직접 확인한 모집요강과 대조했다. 별도 1건은 상세 본문을 읽을 수 없어 분석 완료 건수에서 제외했다. 채용 진행 중인 공고와 마감 공고를 함께 사용한 기능 점검이며, 채용 성공률이나 현업 전문가의 평가를 검증한 것은 아니다.

## 방법과 확인 범위

공통 요청은 “이 공고의 실제 업무와 필수·우대 조건, 준비할 근거를 알려줘”였다. 결과는 공고별 500~800자 안팎의 요약으로 작성했고, 사운드 사례는 900자 이내로 작성했다. 요약 결과를 전체 항목별 분석과 구분했다. 지원자 자료를 만들거나 실제 지원·기업 연락을 수행하지 않았다.

분석 담당 에이전트가 스킬과 해당 직무 지침을 읽고 결과를 작성한 뒤 원문과 대조했으며, 별도 검토에서 누락·요건 강도·조건 충돌을 확인했다. 일반 웹 추출에서 상세 내용이 빠지는 경우 실제 브라우저의 모집요강 영역을 확인했다. 현지화 사례는 본문을 읽은 에이전트가 전달한 자료로 다른 에이전트가 분석했으며, 모든 담당자가 원문을 독립 열람한 것은 아니다.

| 일반 웹 추출은 업무·자격 제목만 남기고 상세 내용을 누락함 | 실제 페이지의 상세 링크·iframe·이미지와 가능한 브라우저 확인을 연결 |

사운드 사례의 고용조건 차이, 현지화의 경력 예외·선택 제출, 배경 아티스트의 직무 구분은 기존 지침으로도 올바르게 처리했다. 이를 실패 사례로 계산하지 않았다. 공고 내부의 차이를 안정적으로 드러내도록 읽기 점검을 명시했으며, 이번 결과만으로 직무별 기준 전체를 다시 작성하지 않았다.

## 수정 후 재검증

이전 출력이나 기대 답안을 제공하지 않은 별도 에이전트가 수정된 스킬로 같은 요청을 다시 수행했다. 실제 공고 4건의 재검증 결과는 다음과 같다.

| 재검증 공고 | 수정 후 확인한 결과 |
| --- | --- |
| 이스트게임즈 클라이언트 | 필수 역량을 C++ 프로젝트 수행 수준으로 유지하고, 개발 환경·우대·제출 형식을 구분 |
| 슈퍼진 QA | 업무 목록을 고정 실행 순서로 바꾸지 않음. 상세 본문의 필수 포트폴리오와 별도 우대를 함께 반영 |
| 드림에이지 밸런스 기획 | 본문 밖 우대, 필수 항목 안의 우대, 경력 대체 조건과 필요역량을 모두 확인 |
| 넥슨게임즈 사업 PM | 별도 우대 누락을 해소하고 필수 제출물·마감 상태·전형 표기 차이를 유지 |

네 결과에서 위에 기록한 요약 오류는 다시 나타나지 않았다. 이는 해당 요청과 공고에 대한 재검증 결과이며 모든 입력에서 같은 품질을 보장한다는 뜻은 아니다.

## 읽을 수 없었던 사례

[111퍼센트 게임 운영 공고](https://www.gamejob.co.kr/Recruit/GI_Read/View?GI_No=284412)는 상세 영역에 [회사 채용 페이지](https://111percent.career.greetinghr.com/o/235023)로 가는 링크만 있었다. 실제 브라우저에서 연결 페이지가 없거나 접근할 수 없다는 안내를 확인했다. 상단 정보는 읽었지만 세부 업무·자격 검증은 완료하지 못했다. 다른 게시물의 내용을 같은 공고로 대체하지 않았다.

## 한계

이 기록은 해당 시점에 읽은 공고와 생성 결과의 대조다. 이후 공고의 변경·마감·삭제 가능성이 있으며, 특정 회사의 연차·도구·제출 조건을 다른 공고의 공통 기준으로 적용하지 않는다. 이번 테스트는 공고 해석과 준비 근거 제안에 한정하며, 실제 지원자의 서류·번역·음원·코드를 심사한 결과는 아니다.
