# 행동 검증 사례

스킬이 실제 입력을 처리할 때 사실·요건을 보존하는지, 중요한 문제를 찾는지, 불필요한 수정을 요구하는지 확인하는 자체 작성 사례입니다. 실제 지원자 개인정보나 기업의 비공개 과제는 포함하지 않습니다. 스킬 설치 폴더에 넣지 않으며 자동으로 실행되는 테스트도 아닙니다.

## 실행 방법

1. 평가할 스킬 버전과 실행 환경을 기록합니다.
2. 새 대화 또는 독립 에이전트에 스킬 경로와 사례 파일만 제공합니다. 사례가 지정한 CSV도 함께 읽게 합니다.
3. 사례의 사용자 요청에 따라 답변을 받고 보존합니다. [판정 기준](expectations.md), 이전 답변, 기대 결과를 평가 대상에 미리 주지 않습니다.
4. 원자료와 판정 기준을 대조해 중요한 누락·잘못된 지적·사실 보존을 확인합니다. 특정 문장이나 소제목의 일치 여부로 통과시키지 않습니다.
5. 스킬의 추가 효과를 보려면 같은 입력을 스킬 없이도 처리하고 비교합니다. 한 번의 출력 차이를 안정적인 성능 향상으로 일반화하지 않습니다.

| 사례 | 확인할 작업 |
|---|---|
| [01 경제 기획](cases/01-economy.md) · [CSV](cases/01-economy.csv) | 실제 수치 오류와 설계 가정 구분, 제한 시간의 수정 우선순위 |
| [02 QA](cases/02-qa.md) | 충분한 기록의 인정, 선택 개선과 필수 보완 구분 |
| [03 제출 준비](cases/03-submission.md) | 제출 경로·기여·AI 표기, 최종 파일 미확인 처리 |
| [04 서버 면접](cases/04-interview.md) | 동시성 주장과 순차 테스트의 차이, 계획과 실행 구분 |
| [05 수정본](cases/05-revision.md) · [CSV](cases/05-revision.csv) | 해결된 지적 인정, 요청 범위 유지 |
| [06 현지화 공고](cases/06-lqa.md) | 대체 경력·선택 제출 보존, 공고 해석의 범위 유지 |

공식 채용 공고는 필요성을 확인하는 자료이지 이 테스트의 정답이나 회사의 심사 기준이 아닙니다. 이번 사례의 세부 조건을 다른 지원 건에 적용하지 않습니다.

최초 실행 결과와 제한은 [실용성 점검 기록](../docs/practical-validation.md)에 있습니다. 실제 PDF·이미지·음원 평가, Claude 실행, 사용자 수정 시간, 채용 결과는 이 사례만으로 검증할 수 없습니다.
