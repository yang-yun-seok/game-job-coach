# 마케팅·커뮤니티·운영 직무

이 문서는 공고에 맞춰 사용하는 코칭 기준이다. 아래 산출물이나 도구를 회사가 요구하지 않은 필수 조건으로 추가하지 않는다.
공통 해석은 [직무별 기준](../role-criteria.md), 충족 상태는 [서류 진단](../document-review.md)을 따른다.
직무명보다 목표·채널·대상·일상 업무·책임 범위를 읽고, 한 경험 안에서도 콘텐츠 제작·광고 집행·서비스 운영을 분리한다.
신입의 동아리·수업·개인 채널·모의 캠페인도 해당 범위의 근거다. 가상 예산·예측 클릭·모의 응대를 실집행·매출·고객 대응 실적으로 쓰지 않는다.
경력은 전략 수립, 제작, 승인, 집행, 모니터링, 위기 대응 중 담당 범위와 의사결정 권한을 공고와 대조한다.

## 브랜드·콘텐츠 마케팅

관찰할 핵심은 대상에게 전달할 메시지와 제작 선택이 캠페인 목적·게임 경험에 연결되는지다.

| 산출물·관찰 증거 | 좋은 근거 | 부족하거나 확인이 필요한 근거 |
|---|---|---|
| 대상·메시지·캠페인 기획 | 대상 행동·핵심 메시지·채널 역할·제작 제약이 연결됨 | 유행 사례를 모았지만 대상과 게임의 연결이 없음 |
| 카피·영상·이미지·콘텐츠 시안 | 실제 결과물과 기획 의도, 수정 전후, 본인 제작/디렉션 범위가 보임 | 게시물 수·사용 도구만 있고 결과물이나 역할이 없음 |
| 콘텐츠 일정·제작 브리프 | 자산·담당·승인·배포 시점과 업데이트 등 의존성이 명확함 | 달력만 있고 목적·확인 조건이 없음 |
| 반응·브랜드 관찰·회고 | 도달·반응의 집계 기준과 정성 반응을 다음 제작 판단에 연결함 | 조회 수만으로 브랜드 선호·구매 전환을 확정함 |

개선 완료 기준:

- 대표 콘텐츠 한 건에 대상·메시지·실제 결과물·본인 기여·변경 이유가 연결된다.
- 목표별 관찰 방법과 배포 조건을 밝히고, 게시 실적과 미게시 시안을 분리했다.
- 외주·협업·기성 자산·생성 도구의 사용 범위를 적고 타인의 작업을 본인 제작물로 쓰지 않았다.

면접 질문:

- “같은 게임을 다른 이용자에게 소개한다면 메시지와 채널을 어떻게 바꾸겠나요?”
- “반응은 높았지만 목표 달성은 불명확했던 콘텐츠에서 무엇을 더 확인했나요?”

## 퍼포먼스 마케팅·UA

UA 소재 제작이 주업무인 공고는 이 문서의 브랜드·콘텐츠와 [아트 기준](art.md) 중 해당 제작 업무를 함께 적용한다. 소재 제작·성과 해석·캠페인 집행 중 본인이 맡는 범위를 구분하고, 영상·이미지 제작자에게 집행 책임을 자동으로 요구하지 않는다.

관찰할 핵심은 광고 가설·집행 조건·측정의 한계를 알고, 비용을 포함한 판단과 개선을 설명하는지다.

| 산출물·관찰 증거 | 좋은 근거 | 부족하거나 확인이 필요한 근거 |
|---|---|---|
| 캠페인 구조·타깃·소재 가설 | 목적, 대상, 매체, 예산, 비교 조건과 변경 이유를 연결함 | 매체명·총예산만 있거나 모의 설정을 실집행처럼 씀 |
| 전환·어트리뷰션 정의 | 이벤트·기간·귀속 창·중복/누락 가능성·데이터 출처를 밝힘 | 서로 다른 귀속 기준의 성과를 그대로 비교함 |
| 소재·입찰·예산 실험 | 바꾼 요소와 유지한 조건, 표본·기간, 중단·확대 기준이 있음 | 동시 변경을 무시하거나 좋은 기간만 선택함 |
| 비용·유저 질·성과 분석 | CPI/CPA/ROAS 등 정의와 비용 범위, 코호트·관찰 기간이 보임 | 저렴한 설치를 가치 높은 유저 확보와 동일시함 |

개선 완료 기준:

- 지표 하나를 원자료 또는 공개 가능한 집계에서 재계산할 수 있고 비용·전환 정의·기간이 분명하다.
- 실집행/공개 데이터 분석/모의 캠페인을 표시하고, 모의 성과는 계산 가정과 시나리오로 남겼다.
- 전후 변화의 다른 원인과 추적 한계를 밝히고, 다음 실험에서 판별할 항목을 정했다.

면접 질문:

- “CPI는 낮아지고 이후 잔존·구매가 나빠졌다면 어떤 집단과 기간을 확인하겠나요?”
- “성과가 좋아진 이유를 소재 변경으로 설명할 때 배제하지 못한 다른 원인은 무엇인가요?”

## 커뮤니티·라이브 운영

관찰할 핵심은 이용자 반응을 서비스 문제와 연결하고 공지·이벤트·모니터링·대응을 일관되게 운영하는지다.

| 산출물·관찰 증거 | 좋은 근거 | 부족하거나 확인이 필요한 근거 |
|---|---|---|
| 공지·운영 정책·응대 기준 | 대상, 사실 확인, 표현 선택, 승인과 수정 기준이 드러남 | 공지 문체만 보고 운영 판단이나 사실 정확성을 확정함 |
| 이벤트·보상·운영 계획 | 참가 조건·일정·예외·중복/악용 방지·종료 확인이 연결됨 | 아이디어만 있고 실제 운영 범위와 예외가 없음 |
| 의견·이슈 분류·전달 | 수집 기간·채널·중복 기준·영향·후속 대응을 설명함 | 큰 목소리의 반응을 전체 이용자 의견으로 일반화함 |
| 장애·갈등 대응·회고 | 확인된 사실·미확인·보고·공지·후속 조치를 구분함 | 삭제·제재 건수만으로 커뮤니티 건강이나 해결을 주장함 |

개선 완료 기준:

- 대표 이슈가 접수→분류→확인→전달/대응→종결 흐름으로 이어지고 본인 권한이 분명하다.
- 이벤트 문서에 참가·보상·예외와 운영자가 확인할 항목이 있으며 실제 진행 여부를 표시했다.
- 참여·잔존·긍정 반응 수치는 채널·기간·분모·수집 편향과 함께 해석했다.

면접 질문:

- “여론이 빠르게 커지지만 사실은 확정되지 않은 상황에서 무엇부터 확인하고 안내하겠나요?”
- “이용자의 요구를 그대로 반영하지 않은 사례에서 판단과 설명을 어떻게 했나요?”

## 고객지원·CS

관찰할 핵심은 요청을 정확히 이해하고 정책·권한 안에서 해결하거나 적절히 전달하며 재발 문제를 찾는지다.

| 산출물·관찰 증거 | 좋은 근거 | 부족하거나 확인이 필요한 근거 |
|---|---|---|
| 익명 응대 사례·답변 템플릿 | 문의 요지·확인 항목·정책 근거·다음 행동·종결 조건이 있음 | 친절한 문장만 있고 해결 범위나 안내 정확성이 불명확함 |
| 분류·에스컬레이션 기준 | 긴급도·영향·필요 정보·담당 부서·전달 시점을 설명함 | 모든 건을 전달하거나 자체 해결을 과장함 |
| FAQ·반복 문의 개선 | 반복 원인과 안내/제품 변경 제안, 반영·확인 범위를 연결함 | FAQ 개수만 있고 이용자 문제나 이후 효과가 없음 |
| 품질·처리 지표 | 응답/해결 시간의 기준, 재문의, 만족도 응답률과 난도를 함께 봄 | 처리량·평균 시간만으로 품질 개선을 확정함 |

개선 완료 기준:

- 실제 익명 사례 또는 명시된 모의 사례에 확인 질문·해결/전달·후속 안내가 빠짐없이 있다.
- 처리 시간·해결률·만족도는 표본·기간·제외 조건·난도·응답률과 본인 담당을 설명한다.
- 보상·환불·제재는 회사 정책과 권한에 따라 판단하고, 법적 권리의 확정 해석으로 대신하지 않는다.

면접 질문:

- “요청을 그대로 처리할 권한이 없을 때 어떤 정보를 확인하고 어떤 선택지를 안내했나요?”
- “처리 시간이 줄었는데 재문의가 늘었다면 성과를 어떻게 다시 해석하겠나요?”

## e스포츠·행사 운영

관찰할 핵심은 참가자·관객·스태프·방송·협력사의 흐름과 의존성을 이해하고 현장 변화를 관리하는지다.

| 산출물·관찰 증거 | 좋은 근거 | 부족하거나 확인이 필요한 근거 |
|---|---|---|
| 행사 목적·일정·런다운 | 대상, 단계별 담당·준비물·전환 조건·시간 의존성이 있음 | 일정만 있고 현장 역할과 준비 상태를 알 수 없음 |
| 대회 규정·접수·진행안 | 참가 조건·대진·판정/이의 절차·결과 확인을 연결함 | 경기 수만 제시하거나 실제 운영과 모의 기획을 혼동함 |
| 현장·방송·협력사 체크 | 전달 책임·연락 체계·장비/공간 확인·장애 시 대안이 있음 | 외주사가 수행한 전체 결과를 본인의 실행으로 주장함 |
| 비용·참여·회고 | 예산 범위, 실제/예상 참가, 만족도 수집 조건, 개선 사항이 드러남 | 관람·시청 수를 중복 처리하거나 노출을 판매 성과로 바꿈 |

개선 완료 기준:

- 대표 행사 한 구간의 담당·순서·진행 신호·예외·연락/보고 경로를 따라갈 수 있다.
- 본인이 기획·섭외·등록·현장·중계·정산 중 맡은 범위를 밝혔고, 참가·관람·시청 집계를 분리했다.
- 학생 대회·동아리 행사는 실제 규모와 제약 안에서 평가하고 상용 리그 경력으로 표현하지 않았다.

면접 질문:

- “경기가 지연되거나 장비가 중단됐을 때 어떤 순서로 상황을 정리하고 누구와 결정했나요?”
- “행사 종료 후 목표 달성·운영 품질·비용을 각각 무엇으로 확인했나요?”

## 모든 세부 직무에 적용할 확인

- 지표에는 정의, 분자/분모 또는 집계 단위, 대상 집단, 관찰 기간, 비교 기준, 유료/자연 유입, 비용 범위, 개인 기여를 붙인다.
- 광고비·매출처럼 절대액인 지표는 통화·총액/순액·산정 범위가 필요하다. 예측 LTV·예상 수익은 실제 관찰 매출과 구분한다.
- 표본 선택·귀속 방식·중복·시즌·게임 업데이트·다른 캠페인을 살핀다. 단순 전후 차이나 상관관계를 인과 효과로 확정하지 않는다.
- ‘유의미하다’는 표현만으로 통계적 유의성을 주장하지 않는다. 검증 방법이 없으면 관찰된 차이와 가능한 설명으로 적는다.
- 경력 성과는 담당 채널·예산 권한·운영 규모·실행 기간·협업자의 역할로 해석하고, 공고에 없는 매체나 최소 집행액을 요구하지 않는다.
- 고객 티켓·계정 정보·커뮤니티 이용자 정보·광고 계정·계약·운영 로그의 기밀 반출을 요구하지 않는다. 익명화·집계·공개 가능한 재구성으로 대체한다.
- 재구성 자료는 실제 사례를 바탕으로 바꾼 범위와 모의 요소를 표시한다. 고객 신원이나 원본 기밀이 없어도 설명 가능한 판단을 평가한다.
- 환불·경품·개인정보·광고 표시·대회 규정의 법적 적정성을 코칭만으로 보증하지 않는다. 필요한 쟁점과 회사 정책/담당자의 확인 범위를 나눈다.
