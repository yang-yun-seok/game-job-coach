# 채용 공고 분석

## 범위와 근거

회사가 맡기려는 일과 확인하려는 역량을 해석한다. 기본 범위는 회사 니즈이며, 지원자의 적합성·자소서 전략·모범 답변은 요청받았을 때만 연결한다.

회사명, 프로젝트·직무명, 명시된 요구 경력, 고용 형태, 담당 업무, 필수 조건, 우대 조건을 확인한다. 명시되지 않은 프로젝트 단계나 경력 수준은 확인 필요로 남긴다. 공고에 없던 신입·주니어·시니어 수준을 추정해 사실처럼 제시하지 않는다.

공고와 공식 자료의 장르·플랫폼·서비스 맥락을 참고하되, 보조 자료에서 새 채용 요건을 만들지 않는다. 특정 항목이 ‘일반 공고보다 강하다’는 비교는 비교 자료가 있을 때만 한다.

[직무 선택과 공통 기준](role-criteria.md)에서 담당 업무에 맞는 세부 직무 지침을 선택한다. 공고 요약에 주된 직무와 분류 근거를 반영하고, 복합 업무나 명칭이 모호한 부분은 따로 밝힌다. 직무 지침의 산출물·검증 신호는 해석의 보조 기준이며 회사가 제출을 요구한 자료와 구분한다.

## 공고 읽기 점검

- 업무·자격 제목만 있고 내용이 비어 있으면 읽기를 끝내지 않는다. 페이지에 실제로 연결된 상세 링크·iframe·이미지와 회사 채용 페이지를 가능한 수단으로 확인한다. 읽지 않은 모집요강을 키워드·기업 소개·일반 직무 지식으로 채우지 않는다.
- 상세 본문과 **상단 경력·고용 형태, 별도 우대, 필요역량, 제출서류·접수 안내**를 대조한다. 한 영역에서 요건을 찾았다고 다른 영역의 조건을 생략하지 않는다. 공고가 명시한 직무 우대와 별도 대상 우대는 구분하고, 지원자가 해당하는지는 제공된 사실 없이 판단하지 않는다.
- 같은 공고 안의 구체화와 모순을 구분한다. ‘포트폴리오 등’에 본문이 필수·형식·기여 표기를 추가하면 함께 반영한다. 정규직과 계약 후 전환처럼 양립하기 어려운 표기는 각각의 위치와 차이를 밝히고 임의로 확정하지 않는다. 공고가 특정 표기를 정정한다고 명시했다면 그 근거를 설명한다.
- 공식 사이트로 이동해 읽었다면 게임잡에서 읽은 정보와 연결된 공식 본문을 구분해 출처를 남긴다. 링크가 삭제·변경됐거나 내용을 읽지 못하면 세부 업무는 미확인으로 둔다. 다른 공고나 과거 버전을 같은 본문처럼 대체하지 않는다.
- 마감된 공고도 직무 분석에 사용할 수 있지만 마감 사실을 밝힌다. 회사나 사이트의 다른 채용이 진행 중이라는 이유로 해당 공고가 현재 유효하다고 말하지 않는다.

## 항목별 해석

담당 업무 → 필수 조건 → 우대 조건의 원래 섹션과 항목 순서를 유지한다. 각 불릿을 독립 단위로 분석하며 중복 내용도 항목 자체를 생략하지 않는다. 복합 항목은 하위 의미로 나누되 원래 항목과 연결한다. 요청이 빠른 요약이면 먼저 요약하고 전체 항목 분석을 했다고 주장하지 않는다.

필수 항목 안의 우대 표현, ‘또는 이에 준하는 역량’ 같은 대체 조건, 선택 제출도 해당 항목과 연결해 보존한다. 한 항목의 예외를 다른 필수 요건의 면제로 넓히지 않는다. 요약은 지원 판단을 바꾸는 조건을 남기고 압축한 범위를 밝힌다. ‘프로젝트 수행 가능’을 ‘기초 지식’으로 낮추거나 업무의 나열 순서를 실제 작업 절차로 바꾸지 않는다. 준비 순서를 제안할 때는 코칭 권고라고 구분한다.

후속 작업에 연결할 때 담당 업무 W01, 필수 조건 M01, 우대 조건 P01처럼 식별한다. 원래 구분이 불명확하면 ‘공고상 미구분’으로 두고 제안 분류를 별도로 표시한다.

각 항목에서 필요한 내용을 짧은 문단이나 표로 설명한다.

- 항목을 찾을 수 있는 짧은 식별구 또는 요약
- 무엇을 다루며 어떤 행동·결과물을 요구하는지
- 품질 기준·제약·협업 상대와 연결되는 역량
- 면접이나 작업물에서 확인하려 할 구체적인 신호
- 해석의 근거와 불확실성

단순 항목은 간결하게 쓰고, 여러 의미가 있는 항목에 설명을 더한다. 매번 동일한 소제목을 반복하거나 앞서 설명한 일반론을 길게 재현하지 않는다. 한 항목에서 얻은 해석을 다른 항목의 명시 요구로 바꾸지 않는다.

## 중요도 해석

공고상 필수·우대 구분은 보존한다. 공고 안에서의 반복, 핵심 업무와의 직접 연결, 명시된 대체 조건을 근거로 준비 우선순위를 설명한다. 우대가 핵심 업무와 밀접해도 회사의 ‘사실상 필수’라고 단정하지 않는다. 필수 항목의 연결이 불명확해도 지원 기준에서 임의로 제외하지 않는다.

‘숨은 의도’ 요청에는 공고가 뒷받침하는 가설과 이를 확인할 질문을 제시한다. 인력 이탈·팀 갈등·일정 위기·프로젝트 실패는 공고만으로 추정하지 않는다. 근거가 없으면 해당 가설을 생략한다.

## 기본 결과

1. 회사가 중요하게 보는 니즈를 최대 3개까지 우선순위와 근거 항목으로 제시한다. 근거가 부족하면 개수를 채우지 않는다.
2. 공고 전체를 짧게 요약하고 기본 정보를 정리한다.
3. 담당 업무·필수·우대 항목을 순서대로 개별 해석한다.
4. 반복되는 역량, 항목 간 연결, 예상 실무 역할을 종합한다.
5. 공고에 연결되는 예상 면접 질문 5개와 확인하려는 역량을 짧게 제시한다. 사용자가 요약만 요청했다면 생략할 수 있다.
6. 확인할 사항과 출처를 남긴다. 출처는 주요 해석 가까이에도 연결한다.

출력 분량은 공고의 복잡도와 사용자의 요청에 맞춘다. 항목 분석을 완료하기 전에 전체를 포괄한 결론을 단정하지 않는다.
